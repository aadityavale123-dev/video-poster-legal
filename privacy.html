Privacy Policy

Last updated: October 17, 2026

This is a personal, single-user tool. It does not collect data from the public.

What is accessed

When the owner signs in with TikTok, the tool receives basic profile information and an access token for the owner's own account, only to upload videos the owner chooses.

Storage

The access token is stored only on the owner's own computer. Nothing is stored on any server or shared with third parties.

Selling or sharing

No data is sold, shared or used for advertising.

Deletion

The owner can revoke access at any time in TikTok settings and delete the local token file.
